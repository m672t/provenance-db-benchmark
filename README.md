# provenance-db-benchmark
# مقایسه تحلیلی پایگاه‌های داده رابطه‌ای و گرافی

## پروژه مقایسه PostgreSQL و Neo4j بر روی دیتاست DARPA THEIA E3

### مشخصات پروژه
- **دیتاست:** برشی از DARPA THEIA E3 (۱ میلیون رکورد)
- **پایگاه داده رابطه‌ای:** PostgreSQL
- **پایگاه داده گرافی:** Neo4j

### ساختار مخزن

| مسیر | توضیح |
|------|--------|
| `postgres/` | فایل‌های مربوط به PostgreSQL |
| `neo4j/` | فایل‌های مربوط به Neo4j |
| `scripts/` | اسکریپت‌های بارگذاری و تست |
| `results/` | نتایج زمان‌بندی کوئری‌ها |
| `report/` | پاسخ سؤالات تحلیلی |
